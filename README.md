指针心得：只是一个地址变量
        A  & 是“定位仪”，* 是“破门锤”。
&的意思  int a = 10; &a=0x7ffe1234
万恶之源 *：身份牌 vs 破门锤 
1，当你写下 int *p = &a; 时，这里的 * 没有任何动作。它只是在向编译器大吼：“老子这个叫 p 的变量不是普通人！我是一张写着地址的房卡（指针）
2，当你在后面的代码里写下 *p = 20; 时，这个 * 瞬间变身成了一把极度暴力的破门锤。一脚踹开门，不管里面原来住着谁（原来的 10），强行把 20 塞进去。
        B  数组 int arr[10] 和指针 int *p 的本质区别：
数组 arr： 是你花重金在市中心买下的一整栋连排别墅，结结实实地占了40个字节的物理地皮（假设一个 int 占4字节）。它是有实体的。
指针 p： 是一张A4纸，上面用笔写着“某某大街1号”。这张纸本身只占区区8个字节（64位系统下），轻飘飘的。
        c  数组指针and指针数组 
数组指针是指向数组的指针      arr=arr【0】；             int (*p)[5];
指针数组是存放指针的数组      int arr[5]={1,2,3,4,5};    int *p[5];
        D  函数指针and函数指针数组
 #include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main()
{
    int (*p)(int,int);

    p = add;

    int result = p(3,5);

    printf("%d\n", result);
}
